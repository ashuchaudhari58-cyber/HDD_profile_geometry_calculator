Reference

How the geometry works

The crossing is modelled as five sections between six points A → B → C → D → E → F: an entry straight (tangent), an entry curve, a horizontal bottom run, an exit curve, and an exit straight.

Section lengths

AB = H1 / sin θ1 − R1 · tan(θ1/2)

BCarc = R1 · θ1    DEarc = R2 · θ2

EF = H2 / sin θ2 − R2 · tan(θ2/2)

CD = TPD − AB·cosθ1 − R1·sinθ1 − R2·sinθ2 − EF·cosθ2

HDD length = AB + BC + CD + DE + EF

Feasibility

The profile is feasible only when every section length is ≥ 0.

Entry tangent needs  H1 ≥ R1·(1 − cos θ1)

Exit tangent needs   H2 ≥ R2·(1 − cos θ2)

Bottom run needs     TPD ≥ curve + tangent horizontals

Symbols: θ = angle · H = depth to bore · R = radius of curvature (ROC) · TPD = total plan distance. Verified against the source spreadsheet (θ=6°, H=6 m, R=900 m, TPD=1500 m → HDD length 1500.46 m).
