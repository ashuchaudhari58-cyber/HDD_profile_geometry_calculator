    ↪️Check 1 · Minimum bend radius

    Minimum design radius of curvature for steel pipe pulled back by HDD.

    Rmin = 1000 × OD(m) × FOS

    Ref: steel HDD design radius ≥ ~1,000–1,200 × OD is a long-standing industry rule of thumb (Faghih, Bayat & Collins, HDD product-pipe bend-radius design literature). FOS 1.2 ≈ the 1,200 × OD rule.
    🛡️Check 2 · Minimum cover depth

    Recommended soil cover above the pipe, based on diameter.

    Ref: cover ≥ 5 × OD for soil arching to develop (PPI Handbook of PE Pipe, Ch.12; ASTM F1962 commentary). PRCI HDD Good Practices Guidelines sets an absolute floor of 15 ft (4.6 m).
    🧭Check 3 · Steering per rod

    Pitch change the driller must make on every rod through the curves.

    Δθ per rod = Lrod / R × 180/π

    Ref: “degrees per joint” = joint length ÷ radius, as in Automated HDD profile calc.xlsx. Check the result against your drill-rod manufacturer's minimum rod bend radius.

    📖 How to use

    1. Pick the crossing type. For river, canal, road and railway crossings you give the obstacle and the minimum cover, and the app works out the minimum entry and exit setback. For Open Ground you enter the depths and plan distance yourself.
    2. Fill the ★ fields. Everything else is optional and has a sensible default.
    3. Basic gives the 5-segment profile, setbacks, cover check, node and station tables. Advanced adds the rod length and turns the same design into a rod-by-rod drilling plan, and can log as-drilled readings against it. Checks compares the design with bend-radius and cover rules of thumb.
    4. Use % / ° to switch how angles are entered and shown. Drillers' pitch in % = 100 × tan(angle).
    5. Pipe gives the pipe specification from the API 5L grade, OD, wall thickness and density: weight per metre, volumes, buoyancy in the drilling fluid and strength. The string length defaults to your design's HDD length. Units converts length, area, volume, mass, force, pressure, density, flow, velocity, torque, energy, power, temperature, angle / slope and more.

    📐 Profile geometry

    The bore is five sections between six points A → B → C → D → E → F: entry tangent, entry curve, horizontal bottom run, exit curve and exit tangent.

    AB = H1 / sin θ1 − R1 · tan(θ1/2)   EF = H2 / sin θ2 − R2 · tan(θ2/2)

    BC = R1 · θ1   DE = R2 · θ2   (θ in radians)

    CD = TPD − AB·cos θ1 − R1·sin θ1 − R2·sin θ2 − EF·cos θ2

    HDD length = AB + BC + CD + DE + EF

    The profile is feasible only if every section is ≥ 0, i.e. H1 ≥ R1(1 − cos θ1), H2 ≥ R2(1 − cos θ2), and the plan distance is long enough for both curves.

    📏 Setback from cover

    Level datum 0 is the bank top (river / canal) or the natural ground (road / railway). Under the obstacle the pipe must stay on or below the min-cover line:

    River / canal bed:  zpipe ≤ −(bed depth) − scour − Cbed

    Bank slopes:  zpipe ≤ ground(x) − Cbank   Road / rail:  zpipe ≤ −C

    The bottom run is set at the lowest point of that line (plus any extra depth). If the curves can't level out that shallow — H < R(1 − cos θ) — the bottom is lowered to the geometric limit and a note is shown.

    The minimum setback is the smallest horizontal distance from the entry (or exit) point to the obstacle edge for which the entry (exit) half of the bore clears the whole min-cover line. It is solved separately for each side by bisection. The pipe only gets deeper as the setback grows, so the answer is unique. Plan distance = entry setback + obstacle width + exit setback. If the two curves would overlap, both setbacks are lengthened equally until they just meet.

    Fixing a setback (for a site-constrained rig position) re-runs the cover check along the full width and flags any point where the pipe is too shallow.

    🔩 Rod-by-rod plan

    Rod k ends at measured depth MDk = L1 + (k − 1)·L (L1 = first rod / tooling length); the last rod is shortened to finish exactly at the exit. Each rod end is placed exactly on the design path:

    Tangent:  x = s·cos θ,  z = z0 − s·sin θ

    Curve:  φ = θ1 − s/R1,  x = xB + R1(sin θ1 − sin φ),  depth = dB + R1(cos φ − cos θ1)

    Steering per rod = L / R × 180/π   (“degrees per joint”)

    Pitch is signed like a walk-over locator: negative = nose down. Inclination from vertical = 90° + pitch; % pitch = 100 · tan(pitch).

    As-drilled readings

    Logged readings use the average-angle method (as in HDD_Pilot_Master_Sheet). The tie-in is the entry angle unless you enter one:

    Δawayk = Lk · cos((θk−1 + θk)/2)   Δzk = Lk · sin((θk−1 + θk)/2)

    Δ elev = as-drilled elevation − planned elevation at the same rod (+ = shallower than plan).
